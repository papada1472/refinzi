# REFINZI v2.1.0 Release Notes

**Production Release: Universal Browser Text & Prompt Layer**
"Better prompts in one click. Expert prompts when it matters."

### Highlights
- ⚡ **Click = Better Prompt**: Instant in-place prompt calibration. Preserves your exact intent and constraints while adding critical technical execution dimensions, structure, and edge-case guards.
- 🧠 **Hold = Expert Prompt**: Hold for 350ms to generate an exhaustive senior execution specification. Never asks questions; applies defensible baseline assumptions, locks deliverable scope, and auto-replaces in-place.
- 🌐 **Universal Browser Text Layer**: Works across ANY editable surface on ANY website (textareas, inputs, ProseMirror, Lexical, Slate, Quill, Draft.js, and AI composers).
- ↩ **Native Undo Preservation**: Replaces text via `insertText`/`execCommand` so the browser's native Undo stack survives. Press `Ctrl+Z` to instantly restore original text.
- ⏱️ **Zero-Friction UX**: Multi-stage kinetic processing feedback, transparent post-apply validation checklist toast, and first-run interactive onboarding modal.
- 🔐 **Privacy First & BYOK**: Zero prompt storage, zero logging, and complete support for user-provided API keys (Google Gemini Flash default, OpenAI, DeepSeek, OpenRouter) or zero-latency local engine.
