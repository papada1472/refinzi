# REFINZI PROMPT ENGINE SPECIFICATION
**Specification Version:** 2.1.0  
**Status:** FROZEN  
**Target Environments:** Universal Browser Text Layer (Any Editable Element & AI Composers)

---

## 1. Product Philosophy & Core Mental Model

Refinzi is **not** a website-restricted wrapper for ChatGPT or Claude. Refinzi is a **universal browser-wide text calibration layer**.

```
                   ANY WEBSITE
                        ↓
               ANY EDITABLE TEXT
                        ↓
                      ORB
                   ↙       ↘
        CLICK (<350ms)    HOLD (≥350ms)
              ↓                 ↓
           BETTER             EXPERT
              ↓                 ↓
        REFINED PROMPT    SENIOR BRIEFING
              ↓                 ↓
         AUTOMATIC IN-PLACE REPLACEMENT
                        ↓
                 DESTINATION AI
```

### The Core Equations

#### Better Mode: Rapid Operational Clarity
$$\text{USER INTENT} + \text{TASK-AWARE MISSING DIMENSIONS} = \text{BETTER PROMPT}$$
- **Latency SLO:** $\le 500\,\text{ms}$ (instant offline deterministic engine).
- **Length Bounds:** 1–3 concise paragraphs ($15\text{--}260$ words).
- **Core Rule:** Identifies the critical parameters that prevent a generic answer. Never wraps input in fluffy boilerplate.

#### Expert Mode: Senior Execution Specification
$$\text{USER INTENT} + \text{TASK SCOPE} + \text{TASK-SPECIFIC MISSING DIMENSIONS} + \text{DEFENSIBLE ASSUMPTIONS} = \text{EXPERT PROMPT}$$
- **Latency SLO:** $\le 3\text{--}4\,\text{s}$ total (streaming with multi-stage kinetic step feedback).
- **Length Bounds:** Structured specification ($50\text{--}1200$ words).
- **Core Rule:** Deeper execution of the user's **exact** task. Never expands scope (hero $\neq$ landing page; email $\neq$ retention strategy; bug fix $\neq$ redesign). Never asks questions to the user.

## 2. Mechanized Quality Gates & Failure Behaviors

Every prompt generated by Refinzi must pass through mechanized, quantifiable quality gates before being applied to the user's document or composer.

| Gate | Measurable Mechanism | CI Metric / Rule | On Failure Behavior |
| :--- | :--- | :--- | :--- |
| **Scope Fidelity** | Deliverable tree diff between raw request and calibrated output. | **Zero new deliverable nodes.** (e.g. hero section prompt cannot contain pricing tiers, FAQs, or testimonial architectures). | **Retry once** (clamp deliverable scope) $\rightarrow$ **Degrade to Better** mode. |
| **Anti-Prestige** | Curated blocklist regex sweep checked against domain allowlist. | **Zero forbidden terms** (`world-class`, `elite`, `renowned`, `top 1%`, `guru`, `expert architect`) unless covered by allowlist. | **Sanitize in-place and pass.** |
| **Intent Fidelity** | Semantic clause preservation & token recall. | **Raw objective clause survives verbatim OR token recall score $\ge 0.9$ (90%).** | **Retry once** (anchor objective clause verbatim) $\rightarrow$ **Degrade to Better** mode. |

### Quantifiable Intent Similarity Algorithm
```typescript
Intent Similarity = (Matched Non-Stopword Tokens + Stem Matches) / Total Non-Stopword Tokens
```
- If the calibrated prompt contains the raw input as a verbatim substring: $\text{Score} = 1.0$.
- Passing threshold: $\text{Score} \ge 0.90$.

## 3. Hold-Interaction State Machine (Frozen)

The Ambient Orb interaction is governed by a deterministic, mutually exclusive state machine:

```
[POINTERDOWN]
      ↓
Starts 350ms Timer + Hold Progress Ring
      ├─ [POINTERUP < 350ms] ─────────→ Fire BETTER Mode (Instant)
      ├─ [DRAG > 6px or SCROLL] ──────→ CANCEL Hold Timer (No trigger)
      └─ [HELD ≥ 350ms]
             ↓
         Orb Glows + Progress Completes + Pill Shows "Release for Expert"
             ↓
         [POINTERUP] ─────────────────→ Fire EXPERT Mode
```

### Interaction Rules
1. **Mutual Exclusivity:** Better Mode and Expert Mode **never** fire on the same gesture.
2. **Cancellation:** Any pointer drag $> 6\,\text{px}$, window scroll, or `Escape` key immediately resets the state machine and aborts the timer.
3. **Orb-first interaction:** the ambient Orb docked by the composer is the interface.
   Click it for a Better prompt; press and hold for an Expert prompt.

## 4. Native Undo Preservation Protocol

Direct assignment to DOM input properties (`element.value = x`) destroys the browser's internal C++ undo history stack. Refinzi preserves native undo through a 3-tier protocol:

1. **`document.execCommand('insertText', false, calibratedText)`:**
   - Pre-selects the text surface (`element.select()`) and dispatches `insertText`.
   - Records the replacement cleanly into the browser's native Undo stack.
2. **Framework Prototype Setter Fallback:**
   - If `execCommand` is blocked by the host site, calls the underlying descriptor setter (`HTMLTextAreaElement.prototype.value`) and dispatches synthetic `InputEvent('input', { inputType: 'insertText' })`.
3. **Global Undo Interception & Safety Net:**
   - In-page capture listener captures `Ctrl+Z` / `Cmd+Z` to restore the pre-calibrated text if native undo was dropped.
   - When Expert Mode output exceeds $350\text{--}400$ words, a 4-second "Undo" safety-net toast is prominently displayed.

## 5. Latency SLOs & Offline Degradation

| Tier | Engine Target | Latency Target | Degradation Strategy |
| :--- | :--- | :--- | :--- |
| **Better Mode** | Local In-Page Engine | $\le 500\,\text{ms}$ (Typical: $10\text{--}50\,\text{ms}$) | Deterministic offline execution. Zero network dependencies. |
| **Expert Mode** | Cloud Model (BYOK / Flash) | $\le 3\text{--}4\,\text{s}$ total | If network fails, provider times out ($>8\,\text{s}$), or extension context is invalidated: **Degrade to Local Expert/Better + one-line notice.** Never hang. Never fail silently. |

## 6. Transparency Taxonomy (KNOWN / INFERRED / ASSUMED)

Refinzi builds user trust by exposing exactly what was known versus what was deduced:

- **`Known: [Entity]`**: Extracted directly from user text (e.g. `"Known: Targeting US Market"`).
- **`Inferred: [Context]`**: Deduced from semantic task domain (e.g. `"Inferred: Node.js 20 runtime"`).
- **`Assumed: [Baseline]`**: Defensible assumptions declared explicitly in prompt (e.g. `"Assumed: Mid-market B2B buyer (stated in prompt as assumption)"`).

Piped directly into the post-apply floating Validation Checklist toast.

## 7. Expert Scope-Lock Escape Hatch

When a senior practitioner reviews a task, adjacent observations often provide high value without changing the deliverable.

Expert Mode appends an out-of-scope appendix that is **never** merged into the primary deliverable:
```markdown
---
[Out-of-Scope Strategic Observations]
(Advisory notes outside the locked deliverable scope):
• Verify subsequent conversion funnel friction post-hero launch.
```
- Scope remains 100% locked.
- Seniority and holistic context are preserved.

## 8. Anti-Prestige Allowlist

Prestige filtering strictly targets hype and generic role filler while permitting legitimate domain terminology:

### Forbidden Hype Terms (Blocked)
`world-class`, `elite`, `renowned`, `top 1%`, `guru`, `expert architect`

### Functional Terms (Allowed by Context)
`expert witness`, `senior engineer`, `specialist`, `subject matter expert`, `domain specialist`, `security specialist`, `technical specialist`, `clinical specialist`

---

## 9. Automated CI Evaluation Harness

The prompt engine is evaluated against a golden benchmark of 50+ prompts across all 6 domains on every commit (`extension/test/prompt_engine_eval.test.ts`):

1. **Anti-Template Check:** Token overlap against `"Act as a {domain} expert: {input}"` must be $< 0.45$.
2. **Scope Lock Check:** Zero unauthorized deliverables (no pricing/FAQ in hero; no strategy in single email).
3. **Prestige Check:** Zero unapproved prestige terms.
4. **Length Bounds:** Better: $15\text{--}260$ words; Expert: $50\text{--}1200$ words.
5. **Intent Fidelity:** Objective clause survival / token similarity $\ge 0.90$.
